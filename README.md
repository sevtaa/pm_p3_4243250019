# Tugas Rutin 3: Kalkulator IP CLI

Aplikasi Command Line Interface (CLI) berbasis Dart untuk menghitung Indeks Prestasi (IP) mahasiswa secara otomatis dengan validasi input, penanganan error (*error handling*), dan pemrosesan data menggunakan *Higher-Order Functions* (HOF).
